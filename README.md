# NovelRipple · 故事涟漪

> 改变一个选择，荡开一整个故事世界。
> Change one moment. Ripple the whole story.

## 产品定位

NovelRipple（中文工作名：**故事涟漪**）是一款分支叙事 / 互动小说创作平台。

- **Novel**：一眼说明与小说有关，同时蕴含"新颖、全新"之意；
- **Ripple**：改变故事中的一个节点后，影响像涟漪一样扩散到人物、伏笔、主线和结局；
- 不把自己限制成单纯的思维导图或 AI 续写器，而是围绕"选择—分支—结局"的创作与阅读体验展开。
