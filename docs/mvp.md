# M0 — First Ripple

## 用户结果

读者可以打开一篇权利清晰的短篇，核对有原文证据的故事地图，改变一个关键事件，先理解连锁影响，再明确确认一条不会覆盖原著的新世界线。

## 最小验收场景

使用公开夹具 `ripple-001`：

1. 从首页进入基准故事；
2. 在故事地图中选择“许澄没有交出红色账簿”；
3. 查看原事件、参与人物和原文证据；
4. 选择“事件不发生”并生成结构化涟漪预览；
5. 看见立即、中期和结局影响，以及严格模式锚点状态；
6. 确认后创建一条子世界线；
7. 刷新页面后仍能看到该世界线，原著基线保持不变。

## M0 范围

### Source

- 接受 UTF-8 `.txt` 与 `.md` 的接口边界；
- 保存原文、规范化文本、内容 Hash 与字符偏移；
- Source 创建后不可修改；
- 当前可操作体验先使用公开基准夹具，真实上传在下一个纵向切片实现。

### Story Map

- Characters、Events、`causes` / `enables` / `foreshadows` 三类边；
- 重要事件至少一个合法 Evidence Reference；
- 用户可以查看证据、选择节点并确认地图版本；
- M0 不提供任意图结构编辑器。

### Ripple Preview

- 支持 `prevent`、`alternate_choice`、`alternate_outcome` 三类分歧；
- 输出立即、中期、结局影响、因果路径、不确定项和 Anchor 状态；
- Impact Plan 是候选，用户确认前不改变正式世界线；
- Anchor 冲突采用 fail-closed，不用巧合强行满足。

### Worldline

- 新世界线引用父世界线、Story Map 版本、Divergence 与已接受 Impact Plan；
- 只保存相对父世界线的增量，不复制原著；
- 创建操作具有幂等键；
- 页面刷新后仍能恢复已创建世界线。

## 明确非目标

- PDF、EPUB、DOCX、网页抓取与 OCR；
- 百万字长篇、批量导入与后台任务系统；
- 多 Agent、多模型路由、模型投票或自动降级；
- 图数据库、向量数据库或通用工作流引擎；
- 完整小说编辑器、无限续写、角色聊天；
- 世界线合并、预生成大量分支；
- 账户、权限、支付、多人协作、分享和发布；
- 移动端专项优化。

## 交付阶段

1. **Foundation**：文档、公开夹具、领域 Schema、不变量测试与可运行 Web 壳；
2. **Traceable Map**：真实 `.txt` / `.md` 导入、结构化模型调用与轻量地图确认；
3. **First Ripple**：真实 Impact Plan、Anchor 检查、持久化 Worldline；
4. **One Scene**：三个后续方向与一个状态一致的完整场景。

当前仓库初始化交付 Foundation，并用确定性夹具走通 First Ripple 的用户形态；它不宣称已经完成真实模型能力。

## 硬门槛

以下任一失败均不能标记对应能力完成：

1. Source 或 canonical worldline 被覆盖；
2. 关键事件缺少合法 Evidence Reference；
3. 图中出现悬空边或不存在的参与人物；
4. Impact Plan 未确认就改变世界线；
5. 严格模式静默破坏 Anchor；
6. 重复确认创建重复世界线；
7. 无效模型输出被宽松解析并写入；
8. 页面刷新后正式状态丢失。
